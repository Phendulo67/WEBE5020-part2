# Monochrome Modelling Agency — Professional Edition

A responsive five-page modelling agency website using a premium black, white and grey editorial aesthetic.

## Pages
- Home
- About
- Models
- Enquiries
- Contact

## Improvements
- Premium editorial typography and spacing
- Stronger visual hierarchy and page consistency
- Responsive layouts for desktop, tablet and mobile
- Collapsing mobile navigation menu
- Animated navigation links and buttons
- Model-card hover effects
- Subtle entrance animation with reduced-motion support
- Improved form styling, labels and autocomplete attributes
- Responsive images using `srcset`, `sizes` and `<picture>`
- SEO-friendly page titles and descriptions
- Professional footer navigation
- Contact page split into clear agency/location cards
- Accessibility improvements including focus states, semantic structure and alt text

## Suggested testing
Test at approximately:
- Desktop: 1366px
- Tablet: 800px
- Mobile: 390px

Check every navigation link, image, form field, hover effect and mobile menu.

> Note: the enquiry form is front-end only. A real submission system would require a backend or form service.
